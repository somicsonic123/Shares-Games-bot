# Shares Games Bot

## Run locally

1. Install Node.js.
2. Copy `.env.example` to `.env`.
3. Put your Discord bot token, application ID, and server ID in `.env`.
4. Run `npm install`.
5. Run `npm start`.

The starter bot provides `/hello`, `/ping`, and `/add` commands.

Never commit `.env`, bot tokens, API keys, or private webhook URLs.
